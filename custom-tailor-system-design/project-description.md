# Project Summary – Custom Tailoring E-commerce System

Developed an e-commerce platform that supports custom tailoring services, combining online shopping experiences with traditional made-to-measure workflows.

The system enables customers to browse products, customize designs, manage measurements, place orders, or book in-store appointments.
It also provides administrative functionalities for managing orders, appointments, and users efficiently.

---

# Role: Team Leader & Business Analyst

Led the project as both Team Leader and Business Analyst, responsible for end-to-end activities from requirement analysis to system design, implementation support, and testing.

---

## 1. Product & Business Analysis

* Analyzed traditional tailoring business processes and transformed them into a digital e-commerce solution
* Designed end-to-end user journeys for two main flows:

  * Online custom ordering (E-commerce flow)
  * In-store appointment booking (Booking flow)
* Gathered and documented business requirements
* Wrote user stories and defined acceptance criteria for key features
* Modeled business workflows and mapped them to use cases

---

## 2. System Analysis & Design

* Defined and decomposed the system into core modules:
  Authentication, User Management, Product Management, Order Management, Appointment Management

* Designed system artifacts including:

  * Use Case Diagrams
  * Sequence Diagrams (following View – Controller – Service – Repository – Database architecture)
  * State Machines for Order and Appointment processes

* Specified detailed workflows for the Authentication module:
  Register, Login, Logout, Reset Password

* Aligned business logic with backend architecture (NestJS-based system)

---

## 3. UI/UX Design

* Designed user interfaces using Figma and Canva

* Developed user flows, navigation logic, wireframes, and mockups for key screens:
  Home, Product Detail, Checkout, Admin Dashboard, Appointment

* Optimized user experience to ensure:

  * Ease of use
  * Clear step-by-step interactions
  * Alignment with e-commerce user behavior

---

## 4. Testing & Quality Assurance

* Performed manual testing for core system functionalities

* Created test scenarios and test cases based on user stories

* Conducted testing on:

  * End-to-end business flows
  * UI/UX consistency
  * APIs using Postman

* Collaborated with developers to identify and resolve issues

---

## 5. Leadership & Collaboration

* Coordinated tasks among cross-functional team members (Developers, Designers)
* Managed project progress using Notion and Google Sheets
* Acted as a bridge between business requirements and technical implementation
* Ensured project delivery aligned with scope and timeline
